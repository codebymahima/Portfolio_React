# Personal Portfolio Website

A modern and responsive portfolio website built using React to showcase my skills, projects, and web development journey.

## Live Demo

🔗 https://portfolio-react-mu-sandy.vercel.app/

## About The Project

This portfolio serves as a central hub for my work, technical skills, and featured projects. It is designed with a clean user interface, responsive layouts, and smooth navigation to provide a seamless experience across devices.

## Features

* Fully responsive design
* Smooth scrolling navigation
* Modern and clean user interface
* Dedicated About section
* Technical Skills showcase
* Featured Projects section
* Resume download functionality
* Contact section with social links

## Tech Stack

* React.js
* JavaScript (ES6+)
* CSS3
* Vite
* Git & GitHub
* Vercel

## Installation

Clone the repository and install dependencies:

```bash
git clone <repository-url>
cd portfolio
npm install
npm run dev
```
